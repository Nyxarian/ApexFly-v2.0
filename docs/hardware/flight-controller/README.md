# ApexFly 飞控主板资料

本目录收录 ApexFly V2.0 飞控主板的展示资源，来源为仓库内 `硬件/PCB`。

## 板卡概览

- 主控：STM32G474VCT6
- 电机接口：M1、M2、M3、M4
- 板载/扩展区域：传感器、LoRa、GPS、PWM 与调试接口
- 资料类型：3D 正反面、PCB 顶面/底面/内层、原理图 PDF/SVG
