# ApexFly V2.0 姿态链路优化 · 环节开发顺序

> 整理时间：2026-09-08
> 配套文件：`姿态链路优化清单（逐环节·含影响结果）.md`（问题与影响）、`姿态链路优化实施顺序（详细版）.md`（含操作细节与回退）
> 本文件用途：**只排列环节顺序**，不排期、不分天。按依赖关系从底到上排列，作为后续推进的"施工顺序表"。

---

## 排序的核心规则

**凡是会改变"测量基准 / 被控对象动态特性 / 环路结构"的环节，必须排在 PID 整定之前；性能增强类放最后。**

理由：在这之前整定出来的 PID 参数，一旦上述环节改动就会失效——等于白调。

三条配套铁律：
1. 每次只改一个环节，改完立刻用黑匣子/台架对比。
2. 每个环节留档：`pid.csv` + 黑匣子场次号 + 一句结论。
3. 凡涉及滤波、频率、控制律的改动，必须重新整定 PID。

> **节拍 → 计时 → 优先级 → PWM（已做）→ 传感器量程/滤波 → 校准（加计 → 零偏 → 零点）→ 解算（滤波 → 门限 → 积分 → 初始化 → 丢拍）→ 控制律（门禁 → 混控下限 → 限幅 → 积分 → 微分 → 速率限制）→ PID 整定 → 性能增强（DMA/中断 → 频率 → 补偿 → 平滑）**
