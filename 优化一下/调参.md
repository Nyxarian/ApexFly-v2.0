## 二、整定的物理逻辑

### 2.1 串级结构

```
摇杆 → 目标角(°) ──[外环 PID]──→ 目标角速度(°/s) ──[内环 PID]──→ 混控修正(us) ──[混控]──→ 四路脉宽
                      ↑                                    ↑
                   当前角度                            当前角速度(陀螺)
```

### 2.2 每个参数管什么

| 参数 | 单位 | 物理作用 | 调大了会怎样 |
|---|---|---|---|
| **内环 Kp** | us / (dps) | 角速度阻尼——转得越快，反向修正越强 | 5~15Hz 高频抖振 |
| **内环 Ki** | us / (dps·s) | 消除稳态角速度误差 | <2Hz 慢振荡 |
| **内环 Kd** | us / (dps/s) | 角加速度阻尼——相位超前，压高频 | 电机嗡鸣、噪声敏感 |
| **外环 Kp** | dps / (°) | 角度刚度——偏得越多，要求转回越快 | 低频来回摆 |
| **外环 Ki** | dps / (°·s) | 消除常值倾角偏差 | 低频呼吸式振荡 |

### 2.3 为什么必须"内环 → 外环"

内环是**快环**（管角速度），外环是**慢环**（管角度）。
先调外环的话，外环输出的"目标角速度"本身就不准，内环再准也只是跟踪一个错的指令——**白调**。

## 三、参数起点

| 参数 | 当前值 | 遥控可调范围 | 备注 |
|---|---|---|---|
| roll/pitch 外环 Kp | **1.80** | 0~50 | 8/29 历史值 |
| roll/pitch 外环 Ki | **0** | 0~50 | 本轮可能开 |
| roll/pitch 外环 Kd | **0.01** | 0~50 | **建议改成 0** |
| roll/pitch 内环 Kp | **1.30** | 0~50 | 8/29 历史值 |
| roll/pitch 内环 Ki | **0** | 0~50 | 本轮可能开 |
| roll/pitch 内环 Kd | **0.01** | 0~50 | 本轮可能加大 |
| 外环 out_max（最大目标角速度） | 200 dps | 20~300 | 同时决定外环 i_limit = 30 |
| 内环 out_max（最大混控修正） | 200 us | 20~300 | 同时决定内环 i_limit = 50 |
| yaw_rate Kp | **0** | 0~50 | 8/29 是 1.20 |
| yaw_angle Kp | **0** | 0~50 | 8/29 是 2.20 |
| hover_pwm_us（满杆油门） | 1550 | 1200~2000 | 悬停杆位约 60~70% |

### 3.1 为什么建议把外环 Kd 设成 0

微分改成对测量求导后（#28），外环 D = −Kd × 实际角速度，**与内环 P 的阻尼作用重复**：

- 内环 P 已经在用"角速度误差"做阻尼；
- 外环 D 又拿"角速度"做一次阻尼，等于同一个量被用了两次；
- 白占一个自由度，还容易在调参时互相干扰。

**编译默认值已经是 0**，但 Flash 里存的是 0.01（影响可忽略）。本轮开始时用遥控把它设成 0。

## 四、阶段 A：地面预检（拆桨，不需要电池）

| # | 检查项 | 方法 | 通过标准 |
|---|---|---|---|
| A1 | 姿态方向 | 手倾斜机体，看黑匣子/遥测的 roll/pitch 符号 | 右倾 roll 为正、抬头 pitch 为正 |
| A2 | 混控极性 | 手倾斜机体，看四路脉宽变化 | 低侧加快、高侧减慢（见 `mixer.h` 的表） |
| A3 | 解锁门禁 | 遥控把内环 Kp 改成 0，再尝试解锁 | **必须被拒绝**（#22 门禁生效） |
| A4 | 限幅不触顶 | 大幅倾斜，看 `motor_us` | 四路都在 1100~2000 内平滑分布，不贴边 |
| A5 | 参数保存/回读 | 遥控 SET → SAVE → 断电重启 | 重启后串口出现 `[BB] pid loaded`，参数仍在 |
| A6 | 无阻塞打印 | 解锁后观察控制周期 | 无 `[D]`/`[RC]` 之类打印（已清理） |
| A7 | 低油门段四路同步 | 油门缓慢推到 1100~1200us | 四路都连续转，无"转一下停一下" |

> **A3 很关键**：每次改参数后都先确认还能解锁，避免参数丢失后静默无阻尼。
>
> **A7** 验证的是 #24 的结论（带桨起转点）。如果出现单路堵转，先回 `环节开发顺序.md` 的 #24 备注处理。

## 五、阶段 B：低空悬停整定（带桨）

### 5.1 安全前提

| 项 | 要求 |
|---|---|
| 场地 | 开阔、无人、草地优先 |
| 高度 | 每轮 0.5~1.5 米，不要高飞 |
| 电池 | 每轮前测电压，低于 3.6V/cell 停止。**低电时推力下降，整定数据不可用** |
| 重心 | 起飞前用手指托两侧，确认重心在几何中心附近 |
| 应急 | 遥控随时可上锁；不要朝有人方向飞 |
| 时长 | 每次飞行 ≤60 秒，落地散热 |
| 天气 | 微风以下（<2 级）。大风会污染所有判据 |

### 5.2 轮 0：基线复现（最重要）

**目的**：确认 #1~#29 的改动没有破坏基本可控性，同时**复现原始问题**（起飞震荡 / 单向漂移）。

| 项 | 内容 |
|---|---|
| 参数 | 全部保持当前值，**一个都不改** |
| 动作 | 起飞 → 悬停 20~30 秒 → 前后左右各打一次杆 → 回中 → 落地 |
| 记录 | 黑匣子场次号、目视现象 |
| 通过标准 | 能离地、能悬停、无高频抖振、无剧烈单侧倾 |

**判据分支**：

| 现象 | 下一步 |
|---|---|
| 能稳定悬停，只有轻微漂移 | ✅ 进轮 1 做微调 |
| 有 5~15Hz 高频抖振 | ❌ 内环 Kp 过大 → 直接进轮 1 降 Kp |
| 起飞就单侧倾 / 翻转 | ❌ **立即停飞**，回阶段 A1/A2 查极性，不要继续调参数 |
| 低频（<2Hz）来回摆 | ❌ 外环 Kp 过大或水平零点有问题 |

> **不要跳过轮 0。** 后面所有调整都要和轮 0 的数据对比，否则不知道是变好还是变坏。

### 5.3 轮 1：内环 P（角速度阻尼）

| 项 | 内容 |
|---|---|
| 改什么 | 只改 roll/pitch **内环 Kp**，两个轴同时改（保持对称） |
| 起始 | 1.30（当前值） |
| 步长 | ×1.3：1.30 → 1.70 → 2.20 → 2.85 → 3.70 |
| 单轮动作 | 起飞悬停 → 轻推机体（或等阵风）制造扰动 → 观察衰减 |

**判据**：

| 现象 | 含义 | 动作 |
|---|---|---|
| 扰动后 **1~2 次摆动内停住** | ✅ 合适 | 记录，继续试探上限 |
| 出现 **5~15Hz 等幅高频抖振**（电机嗡鸣） | Kp 过大 | **回退到上一档 ×0.7**，停止加 |
| 扰动后恢复慢、发飘 | Kp 过小 | 继续加 |
| 黑匣子 rate 曲线呈锯齿/等幅 | 抖振 | 回退 |

**找到上限后**：取"最后稳定档 × 0.8"作为最终值。

### 5.4 轮 2：内环 D（阻尼补充）

**只在轮 1 遇到"想加 Kp 但一加就抖"时才做这一轮。**

| 项 | 内容 |
|---|---|
| 改什么 | roll/pitch **内环 Kd** |
| 起始 | 0.01 |
| 步长 | 0.01 → 0.02 → 0.04 → 0.08 |
| 逻辑 | Kd 提供相位超前，能在同样 Kp 下把高频抖振压下去，从而**允许更高的 Kp** |

**判据**：

| 现象 | 含义 | 动作 |
|---|---|---|
| 加了 Kd 后，原来抖的 Kp 档不抖了 | ✅ 有效 | 可以回头把 Kp 再提一档 |
| 电机持续嗡鸣、机体发热 | Kd 过大 | 回退 |
| 无变化 | Kd 量级不够 | 继续加 |

> **注意**：#28 的 20Hz 低通就是为了让 Kd 能加大。如果 Kd 加到 0.08 还嫌抖，问题多半在机械（桨不平衡、电机振动），不是参数。

### 5.5 轮 3：内环 I（可选）

**只在"松杆后机体以恒定角速度缓慢自转"时才做。**

| 项 | 内容 |
|---|---|
| 改什么 | roll/pitch **内环 Ki** |
| 起始 | 0.02 |
| 步长 | 0.02 → 0.05 → 0.10 |
| 上限保护 | i_limit 自动 = 0.25 × 内环 out_max = 50us（#26） |

**判据**：

| 现象 | 动作 |
|---|---|
| 自转消失 | ✅ 保持 |
| 出现 <2Hz 低频慢摆 | Ki 过大 → ×0.5 |
| 无改善 | 多半是陀螺零偏 → **断电重上电重采零偏**，不要继续加 Ki |

### 5.6 轮 4：外环 P（角度刚度）

> 轮 1~3 期间外环 Kp 保持 1.80 不变（**不能设 0**，否则摇杆失效、无法控制姿态）。

| 项 | 内容 |
|---|---|
| 改什么 | roll/pitch **外环 Kp** |
| 起始 | 1.80 |
| 步长 | ×1.3：1.80 → 2.35 → 3.05 → 4.00 |
| 单轮动作 | 悬停 → 手倾约 20°（或打杆后回中）→ 观察回正 |

**判据**：

| 现象 | 含义 | 动作 |
|---|---|---|
| 松手后 **1~2 次小幅超调内回到 ±1°** | ✅ 合适 | 继续试探 |
| **低频（<2Hz）来回摆** | 外环 Kp 过大 | 回退 ×0.7 |
| 回正慢、有滞后 | 外环 Kp 过小 | 继续加 |
| 回正后停在偏离水平的位置 | 水平零点偏 / 重心偏 | 见第七节 |

### 5.7 轮 5：外环 I（可选）

**只在"松杆后机体停在固定倾角、持续朝一个方向漂"时才做。**

| 项 | 内容 |
|---|---|
| 改什么 | roll/pitch **外环 Ki** |
| 起始 | 0.01 |
| 步长 | 0.01 → 0.03 → 0.05 |
| 上限保护 | i_limit 自动 = 0.15 × 外环 out_max = 30 dps（#26） |

**判据**：

| 现象 | 动作 |
|---|---|
| 固定倾角消失 | ✅ 保持 |
| 出现"呼吸式"低频振荡 | Ki 过大 → ×0.5 |

> **优先级提示**：固定倾角漂移**优先查机械原因**（重心、电机安装倾角、水平零点）。外环 Ki 只是兜底，用 Ki 硬压机械偏差会牺牲动态性能。

### 5.8 轮 6：偏航

| 顺序 | 参数 | 起始 | 判据 |
|---|---|---|---|
| 6a | yaw_rate Kp | 1.20 | 打方向杆机头转动干脆、松杆不摆 |
| 6b | yaw_angle Kp | 2.20 | 松杆后航向保持 |

**前提**：`yaw_angle` 需要磁航向有效，而**磁力计尚未做硬铁校准**（串口提示 `[MAG_CAL] no saved offset`）。

| 选项 | 说明 |
|---|---|
| **本轮只调 6a** | yaw_rate 是纯阻尼，不需要磁力计 |
| 先做磁力计校准 | 遥控 `calmag start` → 缓慢转三轴 → `calmag stop` → SAVE，再调 6b |

> 磁力计校准是 #36（yaw 观测）的前置，可以单独安排。

### 5.9 轮 7：联动综合验证

| 项 | 内容 |
|---|---|
| 动作 | 四路同油门 1100~1300us，手拨/拍击/轻推模拟扰动，持续 12~15 秒 |
| 通过 | 修正连续、无方波抖振、无饱和骑墙（无一路长时间贴 1100 或 2000） |

## 七、常见异常速查表

| 现象 | 最可能原因 | 优先动作 |
|---|---|---|
| 5~15Hz 高频等幅抖振 | 内环 Kp 过大 | 内环 Kp ×0.7 |
| 低频（<2Hz）来回摆 | 外环 Kp 过大 / 积分 windup | 外环 Kp ×0.7 |
| 打杆后大幅过冲、来回摆 | 内环 Kd 不足 | 加内环 Kd |
| 扰动后恢复慢、发飘 | 内环/外环 Kp 过小 | 加 Kp |
| 松杆后缓慢自转 | 陀螺零偏漂 / 内环 Ki 不足 | **重采零偏**，再考虑 Ki |
| 松杆后固定倾角漂移 | 重心偏 / 水平零点偏 / 电机倾角 | **先查机械**，再考虑外环 Ki |
| 电机嗡鸣、机体发热 | Kd 过大或噪声 | 减 Kd |
| 起飞瞬间单侧倾 | 极性错 / 水平零点严重偏 | **立即停飞**，回阶段 A1/A2 |
| 低油门某路不转 | 起转点 > 1100us | 按 #24 备注上调混控下限 |
| 悬停点随电量下降 | 无电压补偿 | 属 #34，本轮不处理 |
| 打杆时目标角变化太慢（手感发软） | #29 斜率限制 200°/s | 可上调到 300°/s（需改代码） |

## 八、黑匣子使用

每轮飞行后：

1. 记下串口打印的场次号（`[BB] session N begin ...`）；
2. 上锁后遥控发 `dump 1` 导出该场次 CSV；
3. CSV 列名：

```
t_ms,roll,pitch,yaw,roll_rate,pitch_rate,yaw_rate,roll_corr,pitch_corr,yaw_corr,
thr,m1,m2,m3,m4,alt_cm,vz_cms,mag_hdg,vz_corr_us,hover_us,alt_state,armed,conn
```

重点看：

| 列 | 用途 |
|---|---|
| `roll` / `pitch` | 松杆姿态偏差、回正超调次数 |
| `roll_rate` / `pitch_rate` | 抖振频率和幅值 |
| `roll_corr` / `pitch_corr` | PID 输出的形状（方波=饱和骑墙，锯齿=抖振） |
| `m1`~`m4` | 是否触顶/触底（1100 或 2000） |
| `thr` | 悬停油门点，用于判断电压影响 |
